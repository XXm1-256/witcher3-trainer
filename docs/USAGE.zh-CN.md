# 玩家指南

解压至可写文件夹，游戏载入存档后打开`Witcher3Modifier.exe`。首页包含金币、倍率和常用开关；鼠标移至圆形i查看用法。顶部“保存开关与倍率”保存设置，“快捷键”统一启停按键。

快捷键全部使用开启Num Lock的小键盘，主键盘数字不触发。小键盘1～8依次为生命、活力、呼吸、无毒性、马匹活力、马匹无恐惧、制作、耐久；9物品不减，0一击必杀。Ctrl＋小键盘1～5依次为传送、无视等级、无视负重、弹药不减、修复装备；6～9依次无落地伤害、昆特获胜、洗点、肾上腺素；Ctrl＋0敌人速度。小键盘/、*、-、+分别为猫眼、移动、跳跃、游泳；Ctrl＋小键盘+为拾取采集。

添加物品后回到角色可移动的场景，让本次操作完成再添加下一件。暂停、剧情与读档可能延迟操作；剧情中无毒性可能无法开启。DLC物品需要安装对应内容。

目录按参考等级筛选，背包按物品实际实例等级筛选。部分目录装备等级由生成规则决定。创建装备先选择基础武器/护甲，再选择词条和目标数值；类型提示标明适用范围。基础固有属性可能形成下限，使用“可达值”调整。预估等级供参考，最终等级和伤害区间以游戏为准；无法自由指定独立使用等级。保存、读档后检查永久保留。

多选删除使用Ctrl点选或Shift连选，每件删除指定数量，数量不足时删完该件；执行前核对清单。

传送先放置当前区域地图标记，再返回游玩场景。复杂地形可能落到桥下或空中，建议搭配无落地伤害。若空中角色模型不显示，可换标记再次传送，通常无需读档。失败会写状态/日志，可继续尝试。

五米拾取采集跳过上锁、任务、特殊交互和偷窃容器，暂停/读档等待后继续。真正的入口/类型校验失败会停止并写日志；部分剧情容器不在覆盖范围内。

日志保存在exe旁，包含诊断地址/版本，分享时截取并脱敏。删除物品或修改装备前保留独立游戏存档。
