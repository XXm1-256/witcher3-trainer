# 玩家指南

[English](USAGE.md)

解压至可写文件夹，游戏载入存档后打开`Witcher3Modifier.exe`。首页包含金币、倍率和常用开关；鼠标移至圆形i查看用法。顶部“保存开关与倍率”保存设置，“快捷键”统一启停按键。

快捷键全部使用开启Num Lock的小键盘，主键盘数字不触发。小键盘1～8依次为生命、活力、呼吸、无毒性、马匹活力、马匹无恐惧、制作、耐久；9物品不减，0一击必杀。Ctrl＋小键盘1～5依次为传送、无视等级、无视负重、弹药不减、修复装备；6～9依次无落地伤害、昆特获胜、洗点、肾上腺素；Ctrl＋0敌人速度。小键盘/、*、-、+分别为猫眼、移动、跳跃、游泳；Ctrl＋小键盘+为拾取采集。

在添加物品页选中物品，设置数量后点击“加入待添加清单”，可继续搜索其他物品；选中右侧清单项可单独改数量。点击“添加清单全部物品”，再回到角色可以移动的画面，让清单依次处理。已完成项不会重复提交，结果未确认的项目先核对游戏背包再决定是否重新加入。暂停、剧情与读档可能延迟操作；剧情中无毒性可能无法开启。添加DLC物品需要安装对应内容。

添加物品和自定义装备页按参考等级查找，背包页按装备当前需要等级筛选。部分装备会在添加时确定等级。创建装备先选基础武器或护甲，再选择词条、填写数值；词条旁的类型说明标明适合哪类装备。某些属性有下限，无法设置时可以使用“可达值”。需要等级随装备和属性变化，不能单独任意指定。最终等级和伤害范围在游戏中查看；保存并读档后可以检查修改是否保留。

背包可按“物品类型”筛选，包括全部武器、全部护甲和具体分类；可叠加名称与需要等级。切换类型后隐藏的选中项不参与删除。多选删除使用Ctrl点选或Shift连选，每件删除指定数量，数量不足时删完该件；执行前核对清单。

传送先放置当前区域地图标记，再返回游玩场景。复杂地形可能落到桥下或空中，建议搭配无落地伤害。若空中角色模型不显示，可换标记再次传送，通常无需读档。失败会写状态/日志，可继续尝试。

开启五米内拾取与采集后，会收取附近容器物品并采集草药。上锁、任务、特殊交互和偷窃容器会跳过；暂停或读档时等待，恢复游玩后继续。若出现错误并停止，查看提示或日志；部分剧情容器不能通过此功能收取。

遇到问题时，可以在反馈中附上提示文字和exe旁modifier.log.jsonl中的相关错误片段。删除物品或修改装备前，保留独立游戏存档。

## 发型与胡须

趣味实验室可选择七种发型。自然胡须有刮净、短胡茬、较长胡茬、短胡须、长胡须；山羊胡、鬓角胡、锚形胡使用固定造型。选好后点击应用，再返回游戏等待外观更新；保存游戏可保留造型。如脸部模型未显示，请停止继续切换并反馈所选款式与日志。
